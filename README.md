## 📌 Project Overview
Modern disaster response is often crippled by the loss of internet connectivity. **Misal_Pav** is a decentralized, mobile application designed to empower volunteers in environments where cellular or Wi-Fi networks are unavailable. Every device acts as an independent data node, allowing for seamless data collection, local peer-to-peer (P2P) synchronization, and intelligent conflict resolution.
