## 📌 Project Overview
[cite_start]Modern disaster response is often crippled by the loss of internet connectivity[cite: 6, 7]. [cite_start]**Misal_Pav** is a decentralized, mobile application designed to empower volunteers in environments where cellular or Wi-Fi networks are unavailable[cite: 2, 13]. [cite_start]Every device acts as an independent data node, allowing for seamless data collection, local peer-to-peer (P2P) synchronization, and intelligent conflict resolution[cite: 13, 17].
